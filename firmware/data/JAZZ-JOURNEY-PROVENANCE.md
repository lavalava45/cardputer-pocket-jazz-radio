# Jazz Journey — historical and pedagogical provenance

Original educational summaries and quiz questions, not transcribed content.
The `jazz-journey.tsv` and `jazz-listen.tsv` source column records an attribution trail, not a song link or permission to redistribute recordings.
Recorded jazz history and stylistic periods overlap; do not assume a broadcast currently plays the genre or the featured musician.

Sources consulted (all HTTPS):
- https://music.si.edu/story/jazz/
- https://jazz.org/education/school-programs/let-freedom-swing/what-is-jazz/
- https://www.nps.gov/jazz/learn/historyculture/history_early.htm
- https://americanhistory.si.edu/explore/projects/smithsonian-jazz/collections-and-archives/latin-jazz/timeline

These files are optional offline SD data. Course progress and diary are private files created only when the user explicitly saves.
