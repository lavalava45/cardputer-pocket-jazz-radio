# Velxio — реальный эмуляторный запуск Pocket Jazz Radio, 2026-11-10

**Статус:** впервые загружена и запущена **наша настоящая ESP32-S3 прошивка** на виртуальном M5Stack Cardputer ADV через Velxio. В отличие от прежнего локального `preview/help-v07k.html`, это **запуск скомпилированного firmware BIN** на виртуальном CPU/периферии. Это не реальный Cardputer и не тест Wi-Fi/ES8311/SD.

## Загрузка и доказательства

- Использован отдельный Chrome window с `https://velxio.dev/example/cardputer-adv-m5-display`. `File → Upload firmware` открывает **настоящий стандартный Windows file picker** с фильтром `Custom Files (*.hex;*.bin;*.elf;*.ihex)`. Ввести абсолютный путь к merged BIN в поле `File name`, затем Open. Background browser DOM-клик раньше не открывал доступного файлового диалога, отсюда прежнее ошибочное предположение, что загрузка заблокирована.
- Успешно выбран и загружен `dist/emulator/0.7k/PocketJazzRadio-v0.7k-EMULATOR-ONLY-DO-NOT-FLASH.bin`. Velxio сообщил **`Loaded binary firmware (8192.0 KB)`**, затем `Run` запустил его. В Serial были `ESP-ROM:esp32s3-20210327`, `[PocketJazz][Clock] TZ loaded=0 rule=UTC0`. На симулированном дисплее появился Pocket Jazz Radio (а не исходный `sketch.ino`, который **остаётся текстом в редакторе** и не отражает загруженный BIN).
- Позднее выбран свежесобранный **v0.7l merged** `dist/emulator/0.7l/PocketJazzRadio-v0.7l-EMULATOR-ONLY-DO-NOT-FLASH.bin` (8 388 608 байт, SHA256 `29940e2810e66e2b217a5ae5b2b5986aef505b961c2bfe029f2b558a648c595a`), выполнены Stop → File → Upload firmware → Open → Run. В Serial вновь появился ESP32-S3 boot и `[PocketJazz][Clock]` при отображении основного радиоэкрана. Редакторный стандартный sketch не модифицировали, `Compile` не нажимали, реальные устройства не подключали.
- Бинарные гарантии: оба эмуляторных образа — по **8 МиБ**, включая загрузчик и тестовую partition table. У v0.7l область `0x10000` **побайтово совпадает** с immutable app-only `dist/releases/0.7l/firmware/PocketJazzRadio-v0.7l-app-only.bin`; таблица с `0x8000` совпадает с локальной компиляцией. **НЕ УСТАНАВЛИВАТЬ merged BIN на физический Cardputer, в M5Launcher/PMan или через USB.**

## Точная граница Wi-Fi

Velxio при загрузке BIN сообщил: прошивка **не знает ни одной сети**, предоставляемой симулятором: `Velxio-GUEST`, `PICSimLabWifi`, `Espressif`, `MasseyWifi` (открытые тестовые сети). У загруженного готового BIN Velxio не подменяет SSID. Без отдельного доверенного Wi-Fi fixture и безопасной настройки учётных данных **нельзя** проверить HTTP/ICY, реальные underruns, CA/NTP, Station Peek, запись K в SD. Нельзя утверждать «Wi-Fi не работает» на настоящем устройстве только по этому испытанию.

## Вывод

**Прежний блокер Velxio по механизму загрузки закрыт.** Доказана работоспособность загрузки/основных экранов/навигации/часов/QR станции в эмуляторе. Не закрыты настоящие Fn-стрелки, физические цвета и читаемость LCD, SD с Jazz Notes/Spark/Likes, MP3/ES8311, буфер и одновременные задачи, безопасность PMan. Устройство и его разделы не менялись.
