# Pocket Jazz Notes — offline C++11 search, U/N и границы

**Состояние v0.7c на 10 ноября 2026:** поиск **подключён в UI, включён в отдельно собранный immutable app-only BIN и прошёл релизные тесты**: клавиша **U** открывает `NOTES_SEARCH`, а **N** пытается показать карточку по имени текущего ICY `Artist - Track`. Историческая формулировка «не подключено к App» неверна. Релиз v0.7c: **99/99 Python, 16/16 MSVC Release C++ (с действующими assert), Arduino compile PASS, 109/109 SHA исходников**. Это **не аппаратная проверка**: приложение не прошивалось и остаётся `NOT CLEARED FOR INSTALL` до read-only проверки PMan; см. [релизный gate](V07C-RELEASE-GATE.md).

## Проверенная база 36 из максимальных 50

Текущие данные: `data/artists-input.csv`, `data/artist-notes.tsv`, `data/artist-notes.idx`. Исходные Miles Davis, John Coltrane и Bill Evans сохранены. Первичная официальная проверка MusicBrainz Artist MBID + Release Group MBID, точного album title, primary type Album и artist-credit, дата и источники записаны в `data/ARTIST-NOTES-PROVENANCE.md`. Основные данные MusicBrainz — CC0, без пользовательских supplementary tags, аннотаций, Википедии и автогенерированных биографий. Альбомы выбраны редактором, не MusicBrainz.

TSV — семь ASCII полей, TAB+LF; размеры полей максимум 48/108/110/100/110/90/40 байт. IDX — `#PJ-NOTES-IDX` версия 1, SHA-256 **точных байтов TSV**, FNV-1a 32-bit, полный ключ и byte offset. SHA — защита консистентности, **не цифровая подпись и не независимая фактологическая проверка**.

## Фактический UX

- **U:** открывает пустой поиск; вводятся только латинские ASCII буквы/цифры/пробел/дефис, максимум **24 символа**. **Enter** выполняет поиск; повторный Enter открывает выбранную карточку. **Fn+A/Fn+D** выбирают результат; **Del** удаляет символ, если строка пустая — выходит в радио; **Tab** выходит.
- **Результаты:** поиск по подстроке slug артиста или title альбома без учёта ASCII-регистра, пробелы запроса сопоставляются с дефисами slug. Массив UI ограничен **тремя** `JazzNote`; отображается полный `notesSearchTotal` с сообщением о дополнительных совпадениях, но постраничного перелистывания следующих результатов пока нет. Не ищет по биографическому полю, альтернативным написаниям, транслитерации, композициям или пользовательским жанровым тегам.
- `searchOfflineNotes()` открывает на SD `/PocketJazz/artist-notes.tsv` и необязательный `artist-notes.idx` **только во время явного поиска**; передаёт File/size и `readNotesFile` в переносимый класс `JazzNotesSearch`, затем закрывает файлы. Это не операция audio/network callback. В объекте используется статическое хранение (~3 КБ, не stack UI).
- **N:** использует нынешнюю ICY-строку `Artist - Track` и отдельное отображение Notes. Сведения по текущему нераспознанному исполнителю **не создаются**. Если карточку открыли через U, Enter/Del возвращают в поиск; после N — к радио.

## Публичный API `PocketJazzRadio/JazzNotesSearch.h`

`NotesFile {void* context; size_t size; bool (*read)(void*, size_t, uint8_t*, size_t)}` — callback случайного чтения **ровно n байт**, без собственной SD-зависимости. Файл и синхронизация принадлежат вызывающему коду. C++11 header без STL/heap/new/malloc/Arduino/network; `JazzNote` содержит ограниченные массивы `key, description, album, artistUrl, albumUrl, attribution, license`.

- `open(tsv, idx)`: строго проверяет TSV — 1..50 записей, ≤32 768 Б, уникальность lowercase artist_key и семь полей. При доступном индексе ≤4096 Б дополнительно проверяет SHA-256, версию, order/hash/key/offset/count; повреждённый IDX **игнорируется** и используется последовательный поиск целой TSV. Если повреждена сама TSV — отказ.
- `ready(), indexed(), rows()` возвращают состояние; `lookup(key,out)` ищет точный slug с binary FNV и разрешением коллизий по полному ключу (или по TSV при отсутствии индекса); `search(query,out,capacity,total)` ограничивает копируемые результаты, но возвращает число всех совпадений.
- Файлы нельзя менять, извлекать SD или закрывать во время операций. Отдельный `open` после смены SD обязателен; потокобезопасность использования общих SD handles без внешнего locking не гарантируется. Пределы размеров не являются измерением физического stack watermark.

## Проверенная публикация и недостающие аппаратные тесты

Независимые `tests/jazz_notes_search_test.cpp`, `tests/jazz-notes-host/CMakeLists.txt`, `tests/test_jazz_notes_search_data.py` проверяют реальные 36 данных, три исходных записи, SHA/index/offsets, битые TSV/IDX, fallback, 50/51 синтетических строк и bounded results. Существуют также `tests/test_jazz_notes_contract.py` и документ происхождения данных. В предыдущем самостоятельном проходе были MSVC Release CTest 20 последовательных PASS и Python 19/19 PASS с активными `assert`; **опубликованный полный v0.7c gate уже включает 99 Python и 16 C++ Release PASS**, подтверждённые архивными `TEST-REPORT.txt` и `HOST-CTEST-REPORT.txt`. В этом **документальном** проходе тесты повторно не запускались.

UI уже содержит U/N **и входит в опубликованный v0.7c BIN**; SD ZIP этой версии сопровождается соответствующей базой из 36 записей. Реальный Cardputer ADV, физическая microSD, клавиатура/Fn, измерения heap/stack, время поиска и извлечение SD во время операции **не проверялись**. Одна лишь офлайн-проверка MusicBrainz не является подтверждением самостоятельных биографических фактов за пределами полей базы; 36 официально проверенных Artist/Release Group ID — не 36 рецензий или авторских биографий. Никакие новые карточки в этом проходе не добавлялись.
