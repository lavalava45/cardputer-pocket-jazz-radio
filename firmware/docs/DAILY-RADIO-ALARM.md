# Pocket Jazz Radio — ежедневный радиобудильник

**Новая пользовательская функция после v0.7s (проект v0.7t до software gate).** Один опциональный ежедневный будильник на уже включённом Cardputer ADV: HH:MM, один из девяти существующих радиопресетов, 60 секунд плавного увеличения громкости. Не нужен второй аудиодекодер или владелец M5.Speaker/ES8311.

## Настройка

1. На радио **Fn+T** открывает экран DAILY RADIO ALARM. Простая T без Fn по-прежнему управляет таймером сна.
2. **Up/Down** меняют час на ±1, **Left/Right** минуту на ±1, **1–9** выбирают заранее сохранённый радиопресет. Пустой пресет нельзя включить.
3. **Enter** включает/отключает будильник с сохранением в NVS; **Del** сохраняет правки и выходит; **X** отменяет несохранённые правки. Данные ограничены по длине, версионированы, защищены контрольной суммой и проверкой readback; неизвестную будущую схему NVS не перезаписываем.
4. Для срабатывания Cardputer должен **оставаться включённым**, часы должны получить NTP-синхронизацию, а выбранный радиопресет должен остаться в каталоге. Автоматического пробуждения полностью выключенного устройства нет.

## Срабатывание и безопасность

- Используется действительное **местное время** из POSIX TZ/фиксированного UTC offset. До NTP-синхронизации — никаких срабатываний. Безопасный запуск с зажатой S также блокирует будильник.
- **Максимум раз в локальный день:** отметка года и дня года сохраняется в NVS до PLAY. Осенью повторный DST-час не запускает второй раз. Весной отсутствующее время пропускается, а не переносится. При откате календаря к ранее уже использованному дню срабатывание консервативно запрещается.
- Пока пользователь слушает Offline MP3, выполняет настройки/SD-операции или вводит Wi-Fi, автоматическое переключение не происходит; будильник может запуститься из Radio, Clock или Signal в указанную минуту. Предыдущий sleep timer при срабатывании отключается.
- Сначала громкость **0**. После первых успешно принятых PCM начинается **60-секундный fade-in**. Ограничение целевой программной громкости M5.Speaker — 24–80 из 255 (даже если обычная громкость была выше). По завершении fade уровень остаётся ограниченным до ручного STOP, без резкого скачка к прежней настройке.
- **Enter** с любого экрана при звучащем будильнике, а также **M** с радио останавливают звук. **−/+** меняют только временную громкость будильника в пределах 0–80, не меняя основной сохранённый уровень. В тот же календарный день после STOP будильник не повторяется.
- Если за **20 секунд** не появились декодированные PCM-кадры, попытка останавливается. Нет бесконечных сетевых попыток и автоматического перехода на локальные файлы SD.
- В NVS сохраняются только конфигурация (версия, флаг, HH:MM, номер пресета) и дата последнего запуска, без URL или Wi-Fi-паролей. **Текущий SD backup PJSET1 пока не включает конфигурацию будильника**; это необходимо учитывать при восстановлении.

## Ограничения испытаний

Программные регрессии проверяют формат, границы, DST, NTP, однократный запуск, fade, единственного владельца аудио и ручную остановку. После gate отдельно нужны настоящие испытания Cardputer: NTP/TZ/reboot, DST, фактическая громкость динамика/наушников, Wi-Fi outage, пользовательские кнопки и отсутствие нарушения других SD-файлов. Нельзя считать компиляцию физическим доказательством громкости.

Возможная будущая переразметка M5Launcher/flash — **отдельная операция с резервной копией и согласованием**, не ограничение на программную разработку. Этот код не изменяет загрузчик, таблицу разделов, данные других приложений и личные файлы microSD.
