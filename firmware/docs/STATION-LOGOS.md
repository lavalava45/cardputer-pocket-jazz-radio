# Локальные логотипы радиостанций (v0.6a)

Логотипы **не обязательны**. Без файла, SD-карты или при любой ошибке формата на основном экране остаётся прежний значок радио. Никакие изображения не скачиваются из сети, а пользовательские файлы SD не изменяются приложением.

## Привязка к станции

Имя: `/PocketJazz/logos/<station-id>.pjlg`, где `<station-id>` — **16 строчных шестнадцатеричных цифр FNV-1a 64** от точных UTF-8 байтов URL станции из M3U/PLS. Это не номер в плейлисте: перестановка станций не меняет имя. Изменение URL (включая параметры запроса и регистр) меняет ID. Хеш не используется как механизм защиты информации или аутентификации.

## Как подготовить файл на ПК

Подготовьте собственную PNG-картинку **строго 64×64 пикселя, RGB или RGBA**. Содержимое должно использоваться с соблюдением прав автора и правил вещателя. Конвертеру нужен Pillow (`python -m pip install Pillow`); сама прошивка не зависит от Pillow.

```powershell
python tools/convert_station_logo.py .\my-logo.png --station-url "https://example.org/jazz.mp3" --output-dir "F:\PocketJazz\logos"
```

Замените URL на **точную** строку из своего плейлиста, а `F:` — на реальную букву карты. Конвертер сам создаёт каталог и рассчитанное имя, не масштабирует исходный PNG и атомарно заменяет только **указанный файл вывода**. В нём можно также явно задать `python tools/convert_station_logo.py my-logo.png output.pjlg`, но тогда правильное имя определяется вручную.

**Формат v1:** 16-байтовый заголовок `PJLG`, версия 1, ширина/высота 64×64, кодирование RGB565 little-endian, длина данных 8192 байта, CRC32/IEEE данных. Размер файла всегда **8208 байт**. Прошивка отвергает неправильный размер, заголовок, недочитанные данные и ошибочный CRC; JPEG/PNG на устройстве не декодируются. RGBA конвертируется на чёрном фоне.

## Ресурсы, интерфейс и ограничения

- В UI выделен один статический кэш **8192 байта**, без динамического выделения памяти для картинки; чтение SD ограничено **8208 байтами/33 операциями read**. Станция и картинка выбираются по URL.
- SD-карта читается только в задаче UI при смене станции или после `R` (перезагрузка плейлистов); в задаче MP3-декодера нет операций с логотипом. Повреждённый/отсутствующий файл не опрашивается повторно каждый кадр.
- Изображение занимает левую панель 64×64. При `V` показывается VU вместо картинки; при повторном `V` логотип возвращается из кэша. Таймер сна перекрывает узкую нижнюю полосу панели.
- Для проверки новых/исправленных логотипов нажмите `R` в радио. Не заменяйте файлы на карте во время их чтения. В поставляемом ZIP пользовательские картинки отсутствуют.
- **Физические SD/LCD, RAM, время чтения и воспроизведение MP3 одновременно с чтением ещё не проверены.** Устройства без PSRAM требуют контроля heap/underrun. До проверки реального свободного APP-слота в M5Launcher 3 PMan увеличенный BIN имеет статус `NOT CLEARED FOR INSTALL`.
