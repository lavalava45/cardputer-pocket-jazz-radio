## Открытые вопросы и диагностика

- **Ограничения preview:** периодический BUFFERING и отдельные случаи неотзывчивости клавиш остаются открытыми проблемами. Не объявлять исправление этих проблем завершённым без воспроизводимого результата.
- [Issue #1 — периодический BUFFERING/звук и отзывчивость клавиш](https://github.com/lavalava45/cardputer-pocket-jazz-radio/issues/1) остаётся открытым **до повторяемого подтверждения исправления**, в частности для Radio Swiss Jazz. Если зависание повторится: STOP → Diagnostics (`I`) → `R` → `incident-*.tsv` с окончанием `END complete=1`, указать станцию/длительность; только тогда точечное исправление.
- [Issue #2 — Jazz Notes: открытие результатов Enter](https://github.com/lavalava45/cardputer-pocket-jazz-radio/issues/2) пока отмечен OPEN; закрывать после фактического теста соответствующего сценария. Остальные отличающиеся аппаратные сценарии фиксировать по конкретным наблюдениям, а не вносить догадки.
- M5Burner/LauncherHub OTA-каталог — **не то же самое**, что GitHub или M5Ware: отдельная заявка **не подавалась**. Для него требуется специальная проверка полного flash-образа/формата, **нельзя выдавать app-only BIN за полный образ**. Не менять M5Launcher, NVS, разметку, личную SD без прямой потребности и согласия.
